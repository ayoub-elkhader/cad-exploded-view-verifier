# Zenodo reassembly example

`aa-swn2.step` is a 3-part STEP assembly, copied **unchanged** from the dataset below. In that dataset its path is `TargetGraph/source/aa-swn2.step`.

```bash
exploded-view-verify examples/zenodo/aa-swn2.step --disassembly
# 3 parts; centroid explosion accepted directly; straight-line disassembly found
```
